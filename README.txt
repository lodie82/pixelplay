PIXELPLAY - PLATEFORME DE JEUX

1. Ouvre index.html pour tester le site sur ton PC.
2. Le jeu est dans jeux/super-pixel-quest/.
3. Pour ajouter un jeu, crée un nouveau dossier dans jeux/ avec son index.html.
4. Ajoute ensuite son nom dans la liste `games` de index.html.
5. Pour mettre le site en ligne, tu peux utiliser GitHub Pages, Cloudflare Pages ou Netlify.

IMPORTANT : utilise uniquement des jeux, images et sons que tu as le droit de publier.
